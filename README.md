# CineSphere

A full-stack movie ticket booking system developed as a CDAC PG-DAC academic project.

## Tech Stack

- React
- Spring Boot
- Spring Security (JWT)
- MySQL
- ASP.NET Core (Payment Service)
- Node.js (PDF Ticket Generation)
- Git
- Postman

## Features

- Movie Catalogue
- Theatre & Show Selection
- Seat Booking
- Payment Integration
- Digital Ticket Generation
- Booking History
- Admin Dashboard
